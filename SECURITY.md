# Security and data handling

Never post an API key, raw feed, private store data or customer information in a public issue. Use a synthetic reproduction and a request ID. For suspected credential exposure, stop using the key and request rotation privately through the [provider profile](https://www.upwork.com/freelancers/~0169e4dcdc3c4f3f65).

This is a limited free pilot, not a production SLA. Client examples are server-side only. Use HTTPS directly, secret-manager/environment credentials and no automatic retries for processing requests. The API's operator routes are not publicly exposed. Report security concerns privately; do not probe another customer's account or submit third-party product data without permission.
